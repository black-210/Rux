# rust++ (.rspp) VS Code Extension

Features:
- Smart completions after `::` (`sdr::`, `math::`, `synth::`, `memory::`, `hardware::`, `power::`, `cpu::`, `gpu::`, `display::`, `kernel::`, `security::`)
- Live Leak Guard (`LG001`–`LG004`), Interval Arithmetic safety checks (`HW302`, `SDR502`), and Bayesian math error diagnostics + QuickFix Auto-Repair via `rspp-lsp`
- Full TextMate highlighting + snippets for `.rspp`
